# 项目 i5 · 统一 UI 美学

两份设计规范，给所有桌面工具定「长什么样」「启动框里写什么」和「产品该有什么行为」，做新工具照着做就行。

## 文件

| 文件 | 内容 |
|---|---|
| `浅色系UI风格指南.md` | 13 节完整规范：色板、字号、间距、按钮、表格、卡片 + 交互与产品设计理念 |
| `Windows启动自检_统一模板.md` | 双击 .bat 后控制台黑框的排版规范：标记符号、分节方式、行宽 |
| `使用说明书.txt` | 使用文档 |

## 核心原则

- **视觉**：浅底、细线、大面积留白。饱和色只用在一颗按钮和一个句号上。
- **行为**：选文件要能拖、用过的要记住、Mac/Win 分两包、交付带说明书。

## 色板速查

```
背景 #f5f6f8   卡片 #ffffff   块中块 #f7f9fc
描边 #d9dee5   正文 #2a2f36   次要 #7a828c
主色 #2f6fed（只当按钮/小色块，不铺大面积）
```

## 适用对象

给「做工具的人」用（包括 AI），不是给最终用户的。做新工具时先读《浅色系UI风格指南.md》拿色板、布局和设计原则，照着做，不要自己发明新样式、新交互。
