# 项目 i5 · 统一 UI 美学

设计规范，给所有桌面工具定「长什么样」「启动框里写什么」「目录怎么分层」和「产品该有什么行为」，做新工具照着做就行。

## 文件

| 文件 | 内容 |
|---|---|
| `浅色系UI风格指南.md` | 完整规范：色板、字号、间距、按钮、表格、卡片 + 交互与产品设计理念 |
| `Windows启动自检_统一模板.md` | 双击 .bat 后控制台黑框的排版规范：标记符号、分节方式、行宽 |
| `统一架构_目录规范.md` | 项目目录四层分层规范（ui / engine / shell / paths），新项目套用 |
| `使用说明书.txt` | 使用文档 |

## 核心原则

- **视觉**：浅底、细线、大面积留白。饱和色只用在一颗按钮和一个句号上。
- **行为**：选文件要能拖、用过的要记住、Mac/Win 分两包、交付带说明书。
- **架构**：代码按 ui / engine / shell 分层，路径来源统一走 `paths.py`。
